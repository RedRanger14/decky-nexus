## Installing the same mod twice at once no longer breaks it

Reported in issue #42, found by mjb-it. If the same mod file was installed twice at the same moment (a manual install while a collection was installing it, a double tap, or a retry while the first try was still going), the two installs shared one download and one extraction folder. One could delete the other's files halfway through, or crash with "No such file or directory".

Each mod file now installs one at a time. A second install of the same file waits for the first and then finishes normally. Checked on a Legion Go 2 by starting two installs of the same mod together: before the fix the second crashed, now both complete.

## Retrying an abandoned installer works

Contributed by mjb-it in PR #40. If you left a mod's installer wizard open for more than 30 minutes and then installed the same mod again, the wizard appeared but nothing was installed. It now installs your choices.

## RAR archives extract properly

Some mods packed with a recent version of WinRAR came out wrong: only a stray file or two was extracted, and the install then said it could not tell where the files go. RAR archives are now extracted with a tool that reads them correctly. This affected every game.

## Kingdom Come: Deliverance (under construction)

New, and marked under construction in the plugin. Mods install into the folder the game loads them from, including mods with an installer and engine mods such as Better Rain, and the most endorsed collection, Fun And Working 2024, installs and loads in game. Mods that change game settings are combined into one settings file instead of replacing each other.
