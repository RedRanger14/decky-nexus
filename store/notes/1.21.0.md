An unofficial, community-built Decky Loader plugin that brings Nexus Mods
to Steam Deck and SteamOS Gaming Mode. Browse, install and manage mods
with a controller, without leaving the couch and without Desktop Mode.
Still in beta.

A **Nexus Mods Premium** account is required, because only Premium
accounts can start a download without a browser.

## Collections no longer say "Everything installed" when a file is missing

Reported in issue #35. A collection often lists more than one file from
the same mod, and the plugin counted a file as installed whenever any file
of that mod was. A file that failed, or that was skipped because a sibling
was already there, stayed missing while the page said everything was in.

The collection page now counts each file the collection lists. Anything
missing shows under "Install remaining" and installs from there. Checking
this on a Legion Go 2 found real gaps in several collections, including a
main mod file in The Witcher 3's Ultimate Mod List and Immersive & Adult's
own resources. If a collection you installed now shows files remaining,
that is why, and pressing the button fills them in.

## The collection switch in My Mods

A collection's switch showed as off whenever the plugin had switched a few
problem mods off on purpose, and switching it back on turned those mods on
again. It now ignores them, and switching the collection on leaves them
off. The count beside it now compares mods with mods, instead of reading
as if a hundred were missing.

## Red Dead Redemption 2 (under construction)

New, and marked under construction in the plugin. Script mods and trainers
load through ScriptHookRDR2, which the game's panel installs in one step,
and collections install it for you. Mods are for Story Mode only: switch
the mod loader off in the panel before playing Red Dead Online.

Mods made for Lenny's Mod Loader need it installed. It is not on Nexus
Mods: download it once from rdr2mods.com into your Downloads folder and
the panel installs it. Mods the plugin cannot make work stay off the
store's home page, and are badged in lists and search.

## Smaller fixes

- "Report a problem" now includes why any recent install failed.
- A file skipped from a collection says why on the page, and no longer
  wears the tick of another file from the same mod.
- Readme folders and Windows desktop.ini files stay out of the game folder.

## Installing

Download `Nexus-Mods-1.21.0.zip` below and install it through Decky
Loader, or add the store URL from the README.
