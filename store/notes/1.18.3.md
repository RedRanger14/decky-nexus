An unofficial, community-built Decky Loader plugin that brings Nexus Mods
to Steam Deck and SteamOS Gaming Mode. Browse, install and manage mods
with a controller, without leaving the couch and without Desktop Mode.
Still in beta.

A **Nexus Mods Premium** account is required, because only Premium
accounts can start a download without a browser.

## Collection mods with an installer no longer get stuck

Reported in issue #35. Some collections record a mod's installer not as
the options the curator picked, but as the exact set of files they ended
up with. The plugin could only read picked options, so those mods waited
under "Finish setup" for a manual choice instead of installing.

They now install from the recorded file set, the same way Vortex does.
Tested with Immersive & Pure on a Legion Go 2: its three mods recorded
this way now install on their own and the collection completes. If you
already have mods waiting under "Finish setup", pressing it after
updating installs them without asking.

## Decky no longer gets stuck after an update

If the plugin was busy with a long download when Decky restarted (for
example during a plugin update), it could stay running in the background
and stop Decky from starting again until a reboot. It now stops its
downloads and closes properly. Interrupted downloads carry on from where
they were.

## Installing

Download `Nexus-Mods-1.18.3.zip` below and install it through Decky
Loader, or add the store URL from the README.
