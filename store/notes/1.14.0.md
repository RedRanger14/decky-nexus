An unofficial, community-built Decky Loader plugin that brings Nexus Mods
to Steam Deck and SteamOS Gaming Mode. Browse, install and manage mods
with a controller, without leaving the couch and without Desktop Mode.
Still in beta.

A **Nexus Mods Premium** account is required, because only Premium
accounts can start a download without a browser.

## NieR:Automata is supported

Requested in issue #25. Tested on a Legion Go 2 with outfit, model and
inventory mods, which install into the game's data folder where it reads
them, and uninstall cleanly.

The HD Texture Pack installs too. It is made for Special K, which crashes
this game on SteamOS, so the plugin builds its textures into the game's
own files during the install instead. The mod page tells you before you
click how many files that is and how much space it needs (about 13.5 GB
for the 1080p pack). Expect a few minutes after the download, with a
progress bar. Uninstalling removes it all.

If another mod already replaces a file the pack improves, the plugin
leaves that mod's file alone and tells you which one. Mods that ship
their own Special K textures, like ANDROIDS REMASTERED, get those built
into their own model.

A NieR mod the plugin cannot install says so on its page before you
click, in plain terms (a program such as LodMod, a ReShade preset, an
install recipe for another mod manager), and the message stays there
instead of flashing past. If an install had to leave part of a mod out,
a note under the mod says what and why.

## Supported games

Baldur's Gate 3, Cyberpunk 2077, Elden Ring, Fallout 4, Fallout: New
Vegas, Helldivers 2, Mass Effect Legendary Edition, Mount & Blade II:
Bannerlord, NieR:Automata, Palworld, Resident Evil 4, Skyrim Special
Edition, Slay the Spire 2, STAR WARS Battlefront II (2017), Stardew
Valley, Starfield, Subnautica, Subnautica 2, Subnautica: Below Zero, The
Witcher 3.

## Installing

Download `Nexus-Mods-1.14.0.zip` below and install it through Decky
Loader, or add the store URL from the README.
