## Kingdom Come: Deliverance is now supported

Kingdom Come: Deliverance is out of "under construction". It was tested on a Legion Go 2 with the 10 most downloaded mods and the 3 most downloaded collections (Fun And Working 2024, Fun & Working 2022, and Realistic & Immersive Overhaul 2023): each one installed, loaded in the game, and played from a save in town.

Some mods were checked in game, not just loaded: Unlimited Saving adds a working Save Game to the pause menu, Unlimited Weight raises the carry limit, and SimpleHUD hides the HUD.

What the plugin handles for you:

- Mods go into the folder the game loads them from, and the game is stopped from moving that folder aside on its first launch with mods.
- Mods with an installer, and engine mods such as Better Rain, install like any other.
- Mods that change game settings are combined into one settings file instead of replacing each other.
- An engine mod's list of game files is added to the game's own list, so an older mod cannot drop the game's newest patch.
