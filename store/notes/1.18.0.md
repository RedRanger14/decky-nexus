An unofficial, community-built Decky Loader plugin that brings Nexus Mods
to Steam Deck and SteamOS Gaming Mode. Browse, install and manage mods
with a controller, without leaving the couch and without Desktop Mode.
Still in beta.

A **Nexus Mods Premium** account is required, because only Premium
accounts can start a download without a browser.

## Valheim is supported

Tested on a Legion Go 2 with single mods and two collections, Valheim
Collection and Valheim Enhanced, played in game.

- Valheim stays the native Linux version. The panel sets up BepInEx, the
  mod loader, in one step using its own Linux launcher, so your
  characters and worlds stay exactly where they are.
- Mods that list their requirements as Thunderstore links (common on
  Valheim, for example Jotunn and JsonDotNET) now resolve to the same mods
  on Nexus, so the plugin can install them.
- Valheim updated to 1.0.16 during testing, and some collection mods have
  not caught up. Valheim Enhanced now installs with its six broken mods
  switched off, and Valheim Collection with Bounties off. Each one says
  why, and can be switched back on in My Mods.

## The plugin notices mods that break, and deals with them

For games that use BepInEx (Valheim, Subnautica, Subnautica: Below Zero),
the plugin reads the mod loader's own log after you play.

- My Mods, the mod's page and the Quick Access panel say which mods did
  not load or hit errors last time you played, in plain words.
- When you quit, any mod that failed constantly during the session is
  switched off for you, with the reason kept on the mod. A mod that hit a
  single error at startup is left alone.
- On Valheim this found the mods behind a stuck console overlay, a camera
  stuck in first person, and a player who could not pick anything up,
  none of which named the mod on screen.

## Collections

- If you already had a mod at a different version from the one a
  collection was built with, the collection page says so, and one button
  switches to the collection's versions.

## Downloads

- A download that crawls on one server now moves to another and carries
  on from where it was. A 714 MB file that one server sent at 13 KB/s
  finished in under 20 seconds from the next.

Download `Nexus-Mods-1.18.0.zip` below and install it through Decky
Loader, or add the store URL from the README.
