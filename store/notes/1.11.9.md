An unofficial, community-built Decky Loader plugin that brings Nexus Mods
to Steam Deck and SteamOS Gaming Mode. Browse, install and manage mods
with a controller, without leaving the couch and without Desktop Mode.
Still in beta.

A **Nexus Mods Premium** account is required, because only Premium
accounts can start a download without a browser.

## Update notes no longer vanish

An update could appear with no release notes and no Show more button,
which is what happened on the test device with 1.11.8.

The notes were being read from GitHub's API, which allows 60
unauthenticated requests an hour for a whole network, not per device.
Once anything on the same connection used those up, the plugin got a
refusal and quietly showed nothing. The store index it reads a moment
earlier has no such limit, which is why the update itself still showed.

The notes now come from the same place as the store index, so if the
update can be seen at all, its notes can be read.

## Installing

Download `Nexus-Mods-1.11.9.zip` below and install it through Decky
Loader, or add the store URL from the README.
