## Red Dead Redemption 2 is now supported

RDR2 is out of "under construction". It was tested end to end on a Legion Go 2 with RedemptiVizion 6.0, a 225-mod collection: reset, install from scratch, then booted and played in Story Mode.

Mods are for Story Mode only. Before playing Red Dead Online, switch the mod loader off in the panel. Mods made for Lenny's Mod Loader need its zip in your Downloads folder, and the panel installs it from there.

### RDR2 fixes

- **Lenny's Mod Loader loads first.** With a big collection it failed about half its boots ("Failed to allocate hooking memory") because other script mods loaded ahead of it. It now loads before them, on new installs and existing ones.
- **The script loaders go in first.** Collections installed ScriptHookRDR2 and the ASI Loader only at the end of the run, so a run cut short left the mods with nothing to load them. They now go in before any mod.
- **RedemptiVizion 6.0 boots.** Seven of its files are now installed switched off, each with a note saying why: five visual overhauls that crash the game together on the current game version, a sniper mod that left Story Mode on a black screen, and the .NET script loader, which crashed the game in the world. Everything else in the collection works, including the upscaled textures.
- **More RDR2 mods install correctly.** These now install:
  - asset mods without an install file;
  - bare stream and replace folders;
  - UI files (.gfx);
  - more texture types.
- **Clearer refusals.** ReShade presets are now named as ReShade presets instead of being treated as hand-copied patches.

### Collections

- **Rules that switch off one file now work in every game.** The installed-mods list didn't give each mod its own file ID, so a rule that switches off one specific file of a mod never matched.
- **The download bar no longer jumps around.** A mod with two files downloading at once made the collection's progress swing back and forth. Progress is now counted per file, by bytes, and never goes backwards.
- **Time left counts bytes, not files.** Big texture packs that download last no longer make a collection look almost done.
